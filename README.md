# liquid_metal_fluid_gallery

Liquid Metal — Fluid Gallery: a WebGL gallery built with React, Three.js (React Three Fiber), and Vite.

**Live:** https://soham-tarabada.github.io/liquid_metal_fluid_gallery/

## Getting Started

```sh
npm install
npm run dev
```

## Scripts

- `npm run dev` — start the dev server
- `npm run build` — typecheck and build for production
- `npm run preview` — preview the production build
- `npm run verify` — typecheck, lint, check shaders, and build

## Deployment

The app is deployed to GitHub Pages (see `homepage` in `package.json` and `base` in `vite.config.ts`). To deploy:

```sh
npm run deploy
```

This builds the app and pushes `dist/` to the `gh-pages` branch.
